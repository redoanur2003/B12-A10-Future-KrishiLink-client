Website name: KrishiLink- Farmer's Growth & Connection Platform (KL-FG&CP).

Live link: https://krishilink-platform.web.app/

Easy Crop Posting: Farmers can add crops with images, price, type, and full details.

Search crop: Users can instantly search crops with smooth, dynamic filtering.

Interest & Response System: Buyers send interest requests; owners accept or reject them.

Auto Quantity Update: Crop quantity updates automatically after interest acceptance.

User Dashboards: Separate pages for My Posts, My Interests, and Profile updates.

Authentication: Login, Register, and Google Sign-In with protected private routes.
